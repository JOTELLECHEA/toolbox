# Particle Properties

Standard Model quick reference. Masses follow PDG conventions — quark masses
are MS-bar except top (pole mass from direct measurements). Check
`pdg.lbl.gov` for current values before quoting any of these in a paper.

### Higgs decay channels <!-- tag:hep, higgs, branching ratio, decay -->

| Channel | Branching ratio | Notes |
|---------|-----------------|-------|
| `H → bb̄` | ~58% | dominant, hard to see over QCD background |
| `H → WW*` | ~21% | one W off-shell at 125 GeV |
| `H → gg` | ~8% | loop-induced |
| `H → ττ` | ~6% | main fermionic channel at the LHC |
| `H → cc̄` | ~3% | |
| `H → ZZ*` | ~3% | "golden channel" via 4ℓ — clean, low rate |
| `H → γγ` | ~0.2% | loop-induced, excellent mass resolution |
